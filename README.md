# 🚀 Machine Learning Projects Portfolio

Welcome to my **Machine Learning Projects Repository**! This repository contains practical projects developed using Python, Machine Learning, Deep Learning, Natural Language Processing (NLP), and Data Visualization.

The objective of these projects is to apply theoretical concepts to real-world problems and develop practical skills in Artificial Intelligence and Machine Learning.

## 📌 Projects

### 1. 📈 Stock Price Predictor
**Technologies:** Python, Pandas, NumPy, Scikit-learn, Streamlit, Plotly, Yahoo Finance

- Predicts the next trading session's stock closing price using historical market data.
- Implements Linear Regression and Random Forest algorithms.
- Evaluates model performance using MAE, RMSE, and R².
- Provides an interactive dashboard for stock price visualization.

### 2. 💬 Twitter Sentiment Analysis
**Technologies:** Python, NLP, NLTK, Scikit-learn, TF-IDF, Streamlit, Plotly

- Classifies tweets into Positive, Negative, and Neutral sentiments.
- Uses Natural Language Processing for text preprocessing.
- Implements TF-IDF for feature extraction.
- Uses Logistic Regression for sentiment classification.
- Supports individual and bulk tweet analysis.
- Visualizes model performance and sentiment distribution.

### 3. 🔢 Handwritten Digit Recognizer
**Technologies:** Python, TensorFlow, Keras, CNN, MNIST, Streamlit, Plotly

- Recognizes handwritten digits from 0 to 9.
- Uses a Convolutional Neural Network (CNN).
- Trains the model using the MNIST dataset.
- Supports handwritten digit drawing and image uploads.
- Displays prediction confidence and probability distributions.

## ⚙️ Installation and Setup

1. Clone this repository:

```bash
git clone https://github.com/YOUR_USERNAME/Machine-Learning-Projects.git
```

2. Navigate to the desired project folder:

```bash
cd Machine-Learning-Projects
```

3. Open the individual project folder and install its dependencies:

```bash
py -m pip install -r requirements.txt
```

4. Follow the individual project's README instructions to run the application.
